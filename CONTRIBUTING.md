# Contributing

OIF is a specification first. Changes to normative text go through a
short RFC:

1. Open a GitHub issue titled `RFC: <change>` stating the problem, the
   proposed text, and what existing boards would have to change.
2. Discussion happens on the issue. The steward merges when there is
   rough consensus and a validator change (if any) accompanies it.
3. Accepted RFCs land as a PR to `SPEC.md` plus `CHANGELOG.md`, and an
   entry in `issues/` tracking implementation.

Tooling changes (validator, converters, skill) are ordinary PRs.

Everything is Apache-2.0. By contributing you agree your contribution
is licensed the same way.
